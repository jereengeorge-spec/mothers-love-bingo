# Mother's Love and Peace Day Bingo

A daily practice bingo card for the 40-day campaign (Nov 1 – Dec 10), plus a 5×5 bingo game with a caller screen for gatherings.

- Daily practice: open the site (progress saves on each phone).
- Bingo game: add `#game` to the link. Caller screen: add `#caller`.

Live page: https://jereengeorge-spec.github.io/mothers-love-bingo/
